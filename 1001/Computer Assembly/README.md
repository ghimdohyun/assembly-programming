# 컴퓨터 조립 실습

## 1. 실습 목적

컴퓨터의 내부 및 외부 구성 요소를 직접 확인하고, 각 부품과 연결 단자의 역할을 이해하기 위해 컴퓨터 조립 실습을 진행하였다.

단순히 컴퓨터를 사용하는 것에서 그치지 않고, 실제 컴퓨터의 구성과 연결 방식을 직접 확인하는 것을 목표로 하였다.

---

## 3. 컴퓨터 외부 확인

먼저 컴퓨터 본체의 후면을 확인하여 각종 연결 단자를 확인하였다.

확인한 주요 영상 출력 단자는 다음과 같다.

* VGA
* DVI

HDMI 및 DisplayPort 단자는 확인되지 않았다.

특히 DVI 단자는 나사로 케이블을 고정할 수 있는 형태이며, VGA는 파란색의 사다리꼴 형태로 되어 있어 두 단자의 외형과 연결 방식을 비교할 수 있었다.

---

## 4. 모니터 연결 확인

사용한 모니터는 HDMI 입력을 지원하였으며, 컴퓨터 본체에는 DVI 출력 단자가 있었다.

따라서 컴퓨터 본체의 DVI 출력과 모니터의 HDMI 입력을 연결하기 위해 DVI to HDMI 케이블을 사용하였다.

### 연결 구조

```text
컴퓨터 본체
DVI 출력
    │
    │ DVI to HDMI 케이블
    ↓
모니터
HDMI 입력
```

DVI 단자는 케이블을 연결한 후 양쪽 나사를 이용하여 고정할 수 있었고, HDMI 단자는 모니터에 직접 꽂는 방식이었다.

---

## 5. 실습 과정

### ① 컴퓨터 본체 확인

컴퓨터의 전원 및 후면 연결부를 확인하였다.

### ② 영상 출력 단자 확인

본체에서 사용할 수 있는 영상 출력 단자를 확인하였다.

```text
VGA
DVI
```

### ③ 모니터 입력 단자 확인

사용할 모니터에서 HDMI 입력 단자를 확인하였다.

### ④ 케이블 연결

컴퓨터의 DVI 단자와 모니터의 HDMI 단자를 DVI to HDMI 케이블로 연결하였다.

### ⑤ 전원 및 화면 출력 확인

전원 케이블과 영상 케이블을 연결한 후 컴퓨터를 부팅하여 화면 출력 여부를 확인하였다.

---

## 6. 실습을 통해 확인한 내용

이번 실습을 통해 컴퓨터의 영상 출력 방식과 각 연결 단자의 차이를 직접 확인할 수 있었다.

특히 DVI, VGA, HDMI와 같이 비슷한 용도로 사용되는 단자라도 형태와 연결 방식이 서로 다르다는 것을 확인하였다.

또한 케이블을 선택할 때 단순히 케이블의 이름만 보는 것이 아니라 **컴퓨터의 출력 단자와 모니터의 입력 단자가 무엇인지 먼저 확인해야 한다는 점**을 알게 되었다.

## 8. 느낀 점

평소에는 컴퓨터를 사용하면서 연결 단자의 종류를 크게 신경 쓰지 않았지만, 직접 연결해보면서 각각의 단자가 어떤 역할을 하는지 확인할 수 있었다.

특히 컴퓨터의 출력 단자와 모니터의 입력 단자가 서로 다른 경우에는 적절한 케이블이나 변환 방법을 선택해야 한다는 것을 알게 되었다.

이번 실습을 통해 하드웨어의 구성과 연결 방식까지 직접 확인해보는 경험을 할 수 있었다.
